# Creating a new Slack App 

This is done from the slack [website](https://api.slack.com/apps).

From this page, a new app can be created and configured. During this time the application is not visible to users. To publish the app, it must be [installed](#installation).

If using the `Create new app` button, a wizard is launched which asks for basic configuration, e.g. name, description, etc., and then some more detailed configuration to make the app useful. Anything added here can be changed later.

There are also templates that provide standard configurations. For this application the **Blank App** template was chosen.

## Configuration

Once the wizard has completed, the app must be [configured](./configuring-a-slack-app.md) further before it will do anything.


## Installation

It is unlikely that you will have persmission to install the application. However, once configured, you can request installation approval using the `Request...` button on the `Settings -> Install App` page. 

Once approved, the same button will be labelled `Install...`; press the button to publish the app.

It is now available in Slack for general use.
